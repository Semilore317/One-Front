# Getting Started

## Requirements
- C++20
- Cmake
- Git

## Clone the repo
```
git clone https://github.com/Semilore317/one-front.git 
cd one-front
```

## Configure the project
```
cmake -S . -B build
```

## Build
```
cmake --build build
```

then run the generated executable in the build directory
