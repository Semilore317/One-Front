One Front is a 2D platforming game built in C++ and Raylib.

It's still very early in development and has only the most basic features and architecture done.

# Getting Started
## Requirements

- CMake
- C++20

## Building
- Git
- Cmake
- C++20 compiler

## Clone the repo
git clone https://github.com/Semilore317/one-front.git cd one-front

## Configure the project
cmake -S . -B build

## Build
cmake --build build

Then run the generated executable in the build directory

## What's still in progress?
- Player animations
- Moving platforms
- Combat
